# **App Name**: Aura

## Core Features:

- Selfie Guard Identity Tool: An AI-powered tool that compares live capture with user data to ensure authenticity and verified status, preventing bot presence.
- One-Touch OTP Login: Seamless number-based authentication using Firebase for high-speed, secure session management.
- Proximal Discover Grid: Clean, cards-only interface showing name, age, and relative distance calculated in real-time from Cloud Firestore data.
- Spectrum Profile Vault: Elegant onboarding for selecting detailed LGBTQ+ identities and orientations within a minimal glassmorphic form.
- Lightweight Message Stream: Real-time, text-only chat system with typing indicators and online status powered by database listeners.
- Safety Shield Calling: Direct integration with the device's native dialer to facilitate safe calls without storing temporary voice media.
- Smart Proximity Pings: Background notifications that trigger when verified users are within the designated 'near me' range.

## Style Guidelines:

- Primary color: Radiant Fuchsia (#D946EF) to symbolize energy and connection.
- Background color: Deep Abyss Black (#0C0B0D) for high-end privacy and modern contrast.
- Accent color: Electric Purple (#A855F7) for soft glow borders and secondary interactive states.
- Primary and Body font: 'Poppins' for a contemporary, avant-garde feel that ensures readability.
- Thin-line minimalist icons with subtle 2px rounded terminals to maintain a human-focused feel.
- Glassmorphic floating cards with a mobile-first column layout and generous padding (32px).
- Spring-based physics for card transitions and micro-interactions, creating a responsive 'real' tactile response.
